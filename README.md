# sync-shift (タイムスケジュール & Googleカレンダー一括連携アプリ)

スマホ・PCの画面上で、1週間のタイムラインをドラッグ操作（またはスワイプ/タッチ操作）で直感的に範囲選択し、指定したGoogleカレンダー（バイト用、プライベート用、事業用など）へ一括登録できるWebアプリケーションです。

## 主な機能
1. **週表示カレンダーグリッド & ドラッグ選択**:
   - 縦軸: 7:00 〜 24:00 (30分刻み)
   - 横軸: 月〜日の7日間
   - マウスドラッグ / スマホのタッチ操作で矩形範囲を選択
2. **週切り替え機能**:
   - 前の週 / 次の週へのページング移動
3. **Googleカレンダー選択 (マルチカレンダー対応)**:
   - 取得したカレンダー一覧から登録先を即座に切り替え可能
4. **Google Calendar API 連携**:
   - OAuth 2.0認証
   - `CalendarList.list` によるカレンダー一覧取得
   - `events.insert` による一括スケジュール登録
